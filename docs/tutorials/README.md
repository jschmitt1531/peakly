# Tutorials

Step-by-step guides. Each uses a file from [`samples/data/`](../../samples/data/) so you can follow along. Screenshots referenced as `docs/img/tutorial-*.png` are added by the maintainers.

| Tutorial | You will learn |
|---|---|
| [CSV and text files](csv.md) | Load a delimited file, fix column mapping, set units |
| [Vendor text exports](vendor-export.md) | Get data out of common chromatography software |
| [Binary and open-standard files](binary-files.md) | Agilent `.ch`, AnDI `.cdf`, mzML |
| [FPLC / UNICORN](fplc-unicorn.md) | Volume axes, UV + conductivity + %B, fractions |
| [Digitize a screenshot](image-screenshot.md) | Calibrate axes and extract a trace from an image |
| [Digitize a photo of a screen or printout](photo-of-screen.md) | Perspective correction and quality checks |
| [Calibration curve](calibration-curve.md) | Standards, fit, weighting, unknowns, LOD/LOQ |
| [Compare runs](compare-runs.md) | Overlay, align, match peaks, ΔRT and area ratio |
| [Integration and peak clipping](integration-and-clipping.md) | Bounds, fused peaks, skims, fits and the audit |
