    Help

    Getting started

    1. Drop files anywhere, or use Open. Several files at once are fine.
    2. For a picture or PDF of a chromatogram, use Image→data to digitize it. Digitized traces carry a digitized badge and ± uncertainty.
    3. Set smoothing, baseline and peak detection for the active trace in the sidebar. Results update as you go.
    4. Add the gradient and column under Method to get %B at elution, k′ and the gradient overlay.
    5. Click ⓘ next to any number in the peak table to see the formula and inputs behind it.

    Privacy

    Peakly has no server. Files are read and processed inside this browser tab and are never uploaded. There are no analytics, trackers, cookies or accounts. The only thing stored locally is your light/dark theme choice. The page loads pinned open-source libraries from public CDNs (Plotly, SheetJS, pako, lz-string, jsPDF, pdf.js). The one exception is the optional Claude image assist in the digitizer: if you start it, that image goes straight from your browser to the Anthropic API under your own API key. The key is held in memory only and is never saved. A share link keeps the data inside the URL fragment (#), which browsers don't send to any server.

    About

    Peakly is free software that runs entirely in your browser. It is independent of, and not affiliated with, any vendor or other chromatography project. Algorithms come from the published literature and are implemented from scratch. Digitized data is an estimate: check critical values against the original instrument data.
